# Hyprland shortcuts

## Launchers and desktop

| Shortcut | Action |
|---|---|
| Super+Return | Open a terminal |
| Super+E | Browse files |
| Super+B | Open the browser |
| Super+A / Super+Shift+Return | Open Raccon Menu |
| Super+Ctrl+Return | Launch applications with Fuzzel |
| Super+V | Pick a clipboard entry |
| Super+N | Toggle notifications |
| Super+P | Choose a display mode |
| Super+W | Browse wallpapers |
| Super+Alt+W | Choose a wallpaper palette |
| Super+Shift+L | Lock the session |
| Super+Ctrl+Q | Open session controls |
| Super+Shift+S | Capture manager (screenshots and recordings) |
| Super+Ctrl+S / Print | Capture a region / the full screen |
| Super+Print | Start or stop a screen recording |
| Super+Shift+Print | Open the folder of the newest capture |

## Windows and workspaces

| Shortcut | Action |
|---|---|
| Super+Q | Close the focused window |
| Super+T | Toggle floating |
| Super+Shift+P | Toggle pseudotiling |
| Super+J | Change the next split direction |
| Super+Left drag / Super+Right drag | Move or resize a window |
| Super+1…9 | Switch to a workspace |
| Super+Alt+1…9 | Move the focused window to a workspace |
| Super+Z / Super+X | Switch to the previous or next workspace |
| Super+S | Toggle the scratch workspace |
| Super+Alt+S | Move the focused window to the scratch workspace |

## Canvas

| Shortcut | Action |
|---|---|
| Super+Arrows | Focus a nearby floating window |
| Super+Alt+Arrows | Pan the canvas |
| Super+Shift+Arrows | Move the focused window |
| Super+Ctrl+Arrows | Resize the focused window |
| Super+C | Center the focused window |
| Super+R | Return to the origin |
| Super+Backspace | Return to the previous camera position |
| Super+Alt+Left drag | Pan by dragging the desktop |
